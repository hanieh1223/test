# راد مدرن — صفحه فرود

صفحه اصلی فارسی و راست‌چین راد مدرن، پیاده‌سازی‌شده با React، TypeScript و Vite.

## پیش‌نیاز
Node.js 20.19+ یا 22.12+ و npm

## اجرای محلی
```bash
npm install
npm run dev
```

آدرس Local که Vite در ترمینال نمایش می‌دهد را در مرورگر باز کنید.

## ساخت نسخه انتشار
```bash
npm run build
npm run preview
```

## نکات فنی
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- پشتیبانی از RTL و زبان فارسی
- منوی موبایل تعاملی و قابل دسترسی با صفحه‌کلید
- رعایت تنظیمات کاهش حرکت سیستم
- پس‌زمینه ویدیویی خارجی با پس‌زمینه CSS جایگزین در صورت عدم بارگیری ویدیو
- فونت Vazirmatn از Google Fonts بارگیری می‌شود
